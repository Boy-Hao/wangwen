# 第十六章 锁拿

崔虎来的时候，带了一队差役，二十来个人，还有一张盖着益都县大印的文书。

他没敢直接冲进营。营门口，秦九带着三十个赈工，横着一排站开了。两边的人，手里都没刀，可谁也没退。

陈默走出来的时候，崔虎正端着那张文书，站在营门外。

“陈默。”他把文书一扬，“私会反军首领郝满仓，通敌叛国。奉周县令之命，即刻锁拿，解送青州。”

“文书我看看。”

崔虎冷笑：“看什么看。你一个白衣异人，也配看县衙的文书。”

陈默没理他，径直走过去，伸手。崔虎不给他。陈默也不跟他争，只是站着，把那张文书上的字，从头到尾看了一遍。

『启明。』

『看了。朱印是真的，周敬之的印。但行文里有个破绽。落款的日期，比周敬之签押的日子早了三天。也就是说，这文书是有人先写好了，逼着周敬之盖印的。』

『谁。』

『按笔迹和行文的口气。沈珏的人。』

陈默了然。

“崔虎。”他说，“这文书，是周县令要拿我，还是沈二公子要拿我。”

崔虎的脸，僵了一下。

“你少攀扯！”

“我不攀扯。”陈默说，“我只问一句。你今日拿了陈默，青州赈工这一摊，谁来接。”

他指了指营里。

“三千赈工，三十队，名册在册。东边八十座水碓，转到一半。青州城外那三十万亩的渠线，我画了二十天，只画了一半。你今天把我锁走，这些活，明天就停。停了，你赔得起吗。”

崔虎握文书的手，紧了紧。

“这是朝廷的事，不是你一个人的事。”

“话是这么说。”陈默说，“可你回头看看。”

崔虎回过头。

营里，那三千个流民，不知什么时候，已经全站起来了。他们不说话，也不上前，就那么密密地站着，看着营门。那三千双眼睛，静静地，像一片没有风的水。

崔虎带来的二十个差役，脸色白了一层。

“你看。”陈默说，“这三千人，是我从流水里捞回来的。他们认我，不认你。你今天要拿我，就是跟这三千人过不去。你手里有二十个人，他们手里有三千条命。这个账，你算得过来吗。”

崔虎的额角，渗出了一层汗。

营外传来一阵马蹄声。

一顶素轿，从官道上缓缓而来。轿子旁边，跟着十几个佩刀的校尉。

顾秉下了轿。

“崔虎。”他站在营门外，声音不大，却让全场静了下来，“谁准你，动本官的赈工。”

崔虎连忙跪下：“顾大人。下官是奉周县令之命……”

“周县令。”顾秉看了他一眼，“一个七品县令，敢动本官的青州赈工，他胆子不小。”

他从袖里抽出一张纸，递过去。

“本官这里，也有一纸文书。青州赈工，直属巡按行辕。没有本官的令，谁也拿不走。”顾秉看着他，一字一顿，“回去告诉周敬之，也告诉那个‘替他盖印的人’。陈默要是少一根头发，本官第一个参的，不是他，是益都县私调乡兵、逼散流民的那笔旧账。”

崔虎跪在地上，半天不敢动。

“还不走。”

崔虎连滚带爬地带着人走了。

陈默站在营门口，看着那顶素轿，和轿边那个瘦得像刀削的人。

“顾大人。”他说，“这一趟，多谢。”

“别谢。”顾秉走近两步，压低了声音，“陈默，本官今日保你，是把本官自己，也押上去了。”

“我知道。”

“你不知道。”顾秉看着他，眼睛很冷，“你私会郝满仓，按律就是死罪。本官保得了你一次，保不了你第二次。你以为，本官是为了你？”

“大人是为了青州。”

“对。”顾秉点头，“本官是为了青州。可光有青州，不够。折子今日就要发出去了，本官向朝廷陈了招抚、屯田的事。可那份折子上去，最快也要一个月。”

“而本官今日，还收到另外一个消息。”

他顿了顿。

“青州刺史调了兵。淮西镇的两千官军，已经开拔，往青州来了。领兵的，是个叫周疵的将军。”

“来做什么。”陈默问。

“剿。”顾秉说，“朝廷不信招抚。朝廷只信刀。两千官军一到，城南那二十万流民，就得成刀下鬼。”

陈默站在那儿，很久没动。

风吹过营门口，那三千个流民还站着，看着他们。

“大人。”陈默终于开口，“官军多久到。”

“八天。”

八天。郝天王给的十天，还剩九天。官军八天就到。

陈默闭上眼。

他脑子里那张青州山川图，在这一瞬间，亮了起来。二十万人的营，三十万亩的地，两千官军，八个昼夜。所有这些，在他意识里，第一次连成了一张完整的网。

『启明。』陈默在心里说，『八天。官军到之前，我得让那二十万人，先长出根来。长在青州的土里。到那时候，谁想剿，都得先掂量掂量。』

『陈默，你算得过来吗。』

他睁开眼，望着城南的方向。

“算不过来。”他说，“可这一次，不能只算。”

“得赌。”
